# 🛒 UMKM E-Catalog – United Tractors

## 📌 Deskripsi Project

UMKM E-Catalog adalah platform website berbasis **multi-vendor katalog produk** yang dirancang untuk membantu pelaku UMKM dalam mempromosikan produk mereka secara digital dalam satu platform terpusat.

Project ini dibuat sebagai solusi atas:

* Tidak adanya katalog UMKM yang terintegrasi
* Promosi yang masih manual dan terpisah
* Kesulitan konsumen dalam menemukan produk UMKM
